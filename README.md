# Skin Disease Detection AI

Deep learning system for skin lesion classification using ResNet, PyTorch, Grad-CAM and Android deployment.

## Overview

Skin cancer is one of the most common oncological diseases worldwide. Early diagnosis significantly increases treatment effectiveness, especially for melanoma.

This project implements an end-to-end artificial intelligence system for skin lesion classification based on dermoscopic images. The solution includes dataset analysis, preprocessing, class imbalance handling, model training, Grad-CAM explainability and Android application integration.

## Key Features

- Multi-class skin lesion classification
- ResNet-based deep learning architecture
- Transfer learning
- Class imbalance compensation
- Focal Loss optimization
- Grad-CAM explainability
- Android application integration
- Probability-based predictions

## Dataset

The model was trained on the ISIC 2019 dataset.

Number of classes:

| Class | Description |
|---------|---------|
| AK | Actinic Keratosis |
| BCC | Basal Cell Carcinoma |
| BKL | Benign Keratosis |
| DF | Dermatofibroma |
| MEL | Melanoma |
| NV | Melanocytic Nevus |
| SCC | Squamous Cell Carcinoma |
| VASC | Vascular Lesions |
